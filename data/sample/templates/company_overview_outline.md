# 회사 소개 발표 자료 목차 (가상 양식)

> CompassPilot 예시 양식입니다. 실제 사내 양식으로 바꿔 쓰세요.
> 관련 요구사항: **POV-001 Customer Presentation** — PPT 또는 PDF로 신청서에 첨부, 약 15장 이내

## 슬라이드 구성 (권장 15장)

| # | 슬라이드 | 채울 내용 |
|---|---|---|
| 1 | 표지 | 회사명, 발표일, 발표자 |
| 2 | 회사 연혁 | 설립 연도, 주요 이정표 |
| 3 | 사무소 위치 | 국내·해외 거점 |
| 4 | 임직원 수 | 전체 인원, 클라우드 인력, AWS 자격 보유 인원 |
| 5 | 고객 현황 | 고객 수, 규모, 산업 분포 |
| 6~8 | M&M 사업 개요 | Assess → Mobilize → Migrate & Modernize 방법론 |
| 9~11 | 주요 AWS 프로젝트 | 고객 사례 2~3건 요약 (성과 수치 포함) |
| 12~13 | AWS 차별화 요소 | AWS에서만 가능한 우리 사업의 강점 |
| 14 | 파트너십 | AWS 파트너 등급, Competency, 수상 |
| 15 | 맺음 | 연락처 |

## 제출 전 체크리스트
- [ ] 15장 이내인가
- [ ] PPT 또는 PDF 형식인가
- [ ] AWS 차별화 요소가 구체적인가 (일반적인 클라우드 강점이 아닌가)
